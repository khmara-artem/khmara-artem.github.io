# Artem Khmara — logo kit

A single line rising from the horizon into a cloud (*khmara* — "cloud"), with a small sun.
Preview all variants at [`/assets/logo/`](index.html).

## Files

| File | Use |
| --- | --- |
| `artem-khmara-primary.svg` | Stacked lockup — mark, name and accent rule. Default logo. |
| `artem-khmara-horizontal.svg` | Mark beside a two-line name — headers, signatures. |
| `artem-khmara-mark.svg` | Mark only, ink + teal sun, for light backgrounds. |
| `artem-khmara-mark-reversed.svg` | Mark for dark backgrounds. |
| `artem-khmara-mark-mono.svg` | One-colour ink mark. |
| `artem-khmara-mark-white.svg` | One-colour white mark, for photos or the teal ground. |
| `artem-khmara-icon-dark.svg` / `-light.svg` / `-accent.svg` | 200×200 rounded-square avatars and app icons. |
| `favicon.svg` | Browser tab icon. |
| `artem-khmara-logo-overview.png` | Full system on one sheet. |

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Ink | `#1E2A3A` | Line, type, dark ground |
| Teal | `#4E8B82` | Sun, accent rule, accent ground |
| Mist | `#F4F6F5` | Light ground, reversed line |
| Rule | `#D5DBD9` | Hairline borders |

## Type

- **Unbounded 500**, uppercase, wide tracking — the name.
- **Manrope 500/600** — supporting text.

Both are free on Google Fonts. The wordmark SVGs use live text set in Unbounded, so they
render correctly on pages that load the font. For print or tools without it, open the file
in Figma or Inkscape and convert the text to outlines first. The mark, icons and favicon
are pure geometry and work anywhere.

## Usage

- Keep clear space around the logo of at least the sun's diameter × 4.
- Don't recolour the line in anything but Ink, Mist or white; the sun is Teal or Ink.
- Don't stretch, rotate, or add effects.
